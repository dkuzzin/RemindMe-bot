# RemindMe Bot

Небольшой Telegram-бот для создания и управления напоминаниями.

Бот позволяет задавать дату и время обычным текстом, например `завтра 09:30` или `через 2 часа`, а затем отправляет сообщение в нужный момент.

> Бот: `@dnRemind_bot`
> Сейчас отключён.

## Возможности

* создание напоминаний;
* распознавание дат и времени;
* просмотр списка напоминаний;
* перенос напоминания на другую дату;
* удаление напоминаний;
* отметка напоминания как выполненного;
* повторное использование уже прошедшего напоминания;
* автоматическая отправка уведомлений;
* удаление старых завершённых напоминаний.

## Примеры дат

При создании или переносе напоминания можно использовать разные варианты записи:

```text
15 сентября 13:00
завтра 09:30
через 2 часа
```

Для разбора дат используется python библиотека `dateparser`.

## Как это работает

После создания напоминания бот сохраняет его вместе с датой и статусом выполнения.

В фоне работает отдельный поток, который периодически проверяет сохранённые напоминания. Когда наступает нужное время, бот отправляет пользователю сообщение и отмечает напоминание как завершённое.

Напоминания хранятся локально в JSON-файле.

## Используемые технологии

* Python
* Telegram Bot API
* `pyTelegramBotAPI`
* `dateparser`
* JSON
* `threading`
